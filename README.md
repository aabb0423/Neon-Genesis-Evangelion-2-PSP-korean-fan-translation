1. 패치 적용 방법

PSP 일본판 ULJS-00064 1.01의 수정하지 않은 원본 ISO와 xdeltaUI가 필요합니다.

1) ZIP의 압축을 풉니다. xdeltaUI.exe와 xdeltaUI에 동봉된 xdelta.exe를 같은 폴더에 둡니다.
2) xdeltaUI를 실행하고 Apply Patch 탭을 엽니다.
3) Patch에 Eva2_AnotherCases_KR_2026-11-24-final.xdelta을 선택합니다.
4) Source File에 일본판 원본 ISO를 선택합니다.
5) Output File에 원본과 다른 경로 또는 이름을 지정합니다. 파일명 끝에 .iso를 붙입니다.
6) Patch를 눌러 적용합니다. 완료되면 새로 생성된 ISO를 사용합니다.

다른 패치가 적용된 ISO를 선택하면 원본 불일치 오류가 날 수 있습니다.
그 경우 Source File에서 수정하지 않은 일본판 원본 ISO를 다시 선택해 주세요.
